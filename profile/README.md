## 🚀 Introduction
So what is RetroArch? RetroArch for Windows is a free, open-source frontend built on the libretro design that consolidates many emulator and game engines into one consistent program. Each engine runs as a core you load inside the app, which means a single interface, a single set of controls, and a single place to keep your playlists and settings. For a Windows user who wants tidy organization instead of a scattered collection of standalone tools, RetroArch turns many separate systems into one coherent experience.

## ✨ Highlights

### Play and organize
- **Modular cores** — install RetroArch cores through the built-in updater and switch between systems without closing the app.
- **Playlists** — scan folders of content you own so everything is grouped and easy to browse from the main menu.
- **Save states** — freeze and resume your session instantly on cores that support it.

### Tune and connect
- **Shaders** — apply CRT, scanline, and smoothing effects to reshape how content looks on modern panels.
- **Input mapping** — supported controllers are detected and configured automatically, with room for manual remaps.
- **RetroAchievements** — opt in to track progress and unlock achievements on cores that offer them.

## 🎯 Getting Up and Running
1. Launch RetroArch and explore the menu with your keyboard or a paired controller.
2. Fetch a core via **Load Core** and the built-in updater.
3. Use **Load Content** to open a file you legally own for that core.
4. Bring up the quick menu to enable shaders, save states, or rewind while you play.
5. Save your configuration so RetroArch reopens exactly the way you left it.

## ❓ Common Questions
**Is RetroArch free and open-source?**
Yes. RetroArch is fully free and open-source, developed in the open with no paid unlocks or subscriptions.

**What do I do about a RetroArch BIOS requirement?**
Certain cores need original BIOS or system files for accurate operation. RetroArch does not include or distribute copyrighted BIOS, firmware, or games, so you must supply any required files yourself from hardware you legally own.

**Is my configuration data secure?**
Your settings, playlists, and save data are stored locally in plain files on your own PC, so you stay in control of your information and can back it up whenever you like.
